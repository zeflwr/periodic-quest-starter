# Periodic Quest

An educational chemistry RPG prototype where elements become characters with powers based on their real chemical properties.

## 🚀 How to Play
1. Open `index.html` in your browser (or visit the GitHub Pages link if published).
2. Click on an element card to learn basic facts.

## 📂 Project Files
- `index.html` — main game page
- `styles.css` — styling
- `main.js` — game logic
- `data/elements.json` — element data
- `README.md` — project info
